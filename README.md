# AI FACE PAY

얼굴 인식으로 로그인하는 미래형 핀테크 주식 투자 체험 웹 애플리케이션입니다.

## 프로젝트 개요

웹캠으로 얼굴을 인식한 뒤, 가상 주식을 자동 매수하고 실시간 가격 변동을 보며 스페이스바로 매도하는 투자 시뮬레이션입니다.

## 기술 스택

| 영역 | 기술 |
|------|------|
| 백엔드 | Python, Flask |
| 얼굴 인식 | OpenCV (Haar Cascade) |
| 프론트엔드 | HTML, CSS, JavaScript |
| 차트 | Chart.js |

## 프로젝트 구조

```
facepay/
├── app.py                              # Flask 서버 (라우팅, 얼굴 인식)
├── haarcascade_frontalface_default.xml # OpenCV 얼굴 감지 모델
├── templates/
│   ├── index.html                      # 메인 페이지
│   ├── select.html                     # 기업 선택 페이지
│   └── trade.html                      # 투자 체험 페이지
├── static/
│   ├── style.css                       # 공통 스타일
│   ├── index.js                        # 메인 페이지 스크립트
│   ├── select.js                       # 기업 선택 스크립트
│   └── trade.js                        # 투자 체험 핵심 로직
└── faces/                              # 얼굴 이미지 저장소
```

## 서비스 흐름

```
메인 페이지 (/) → FACE PAY 시작 버튼
    ↓
얼굴 인식 (/face_login) → 웹캠으로 얼굴 감지
    ↓
기업 선택 (/select) → 투자할 주식 선택
    ↓
투자 체험 (/trade/<stock>) → 실시간 매매 시뮬레이션
```

## 주요 기능

### 1. 얼굴 인식 로그인
- OpenCV Haar Cascade 알고리즘으로 실시간 얼굴 감지
- 얼굴 감지 시 화면에 초록 박스와 `FACE VERIFIED` 텍스트 표시
- 인식 성공 후 1.5초 대기 후 자동으로 기업 선택 페이지로 이동

### 2. 가상 주식 목록

| 종목명 | 시작가 |
|--------|--------|
| FACE_TECH | 1,000원 |
| AI_BANK | 1,200원 |
| META_PAY | 900원 |
| SMART_COIN | 1,500원 |
| FIN_AI | 1,300원 |

### 3. 실시간 투자 체험
- 게임 시작과 동시에 **10주 자동 매수**
- **1초마다** 가격이 -40 ~ +40원 범위로 랜덤 변동
- **20초마다** 긍정/부정 뉴스 공시 발생 → 가격 급등/급락 (±0~200원)
- **60초 타이머** 종료 시 게임 종료
- **스페이스바** 입력으로 즉시 매도 → 수익률(%) 계산 및 표시
- Chart.js로 실시간 주가 차트 시각화

### 4. 뉴스 공시 시스템

| 유형 | 예시 뉴스 | 효과 |
|------|-----------|------|
| 긍정 | AI 투자 유치 성공, 글로벌 진출 성공 | 가격 상승, 초록 배경 |
| 부정 | 개인정보 논란 발생, 보안 문제 발생 | 가격 하락, 빨간 배경 |

## 설치 및 실행

```bash
# 가상환경 활성화
.venv\Scripts\activate

# 패키지 설치
pip install flask opencv-python

# 서버 실행
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속

## 주의사항

- 웹캠이 연결된 환경에서 실행해야 합니다
- 얼굴 인식은 서버 측(로컬 머신)에서 OpenCV로 처리됩니다
- ESC 키로 얼굴 인식 화면을 강제 종료할 수 있습니다
