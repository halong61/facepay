# FacePay — 실시간 산업별 주식 시뮬레이터

순수 HTML / CSS / JS로 구현된 주식 투자 시뮬레이터입니다.  
별도 서버, 파이썬, 가상환경 없이 HTML 파일만 열면 바로 실행됩니다.

---

## 파일 구성

| 파일 | 역할 |
|------|------|
| `index_1.html` | 거래 화면 (매수 / 매도) |
| `index_2.html` | 차트 전용 화면 (듀얼 모니터용) |
| `stock.js` | 가격 엔진, 차트, 뉴스, 거래 로직 |
| `web_style.css` | 전체 스타일 |

## 가격 엔진

- **틱 주기** — 500ms마다 시스템 시각을 확인, 초가 바뀌면 1틱 처리
- **변동폭** — 틱당 ±3.5% 결정론적 변동 (시드 기반)
- **스무딩** — 이전 변동률 65% 유지 → 부드러운 곡선
- **상하한 클램핑** — 초기가 기준 ×0.5 ~ ×2 범위 이탈 불가

---

## 멀티 컴퓨터 동기화

- **시드 기반 난수** (`seededRand`) — 오늘 날짜를 시드로 사용, 완전 결정론적
- **자정부터 재현** (`buildHistory`) — 페이지 열릴 때 자정(00:00:00)부터 현재까지 모든 틱을 재현
- **실시간 시각 동기** — `setInterval` 드리프트 방지를 위해 매 틱 `new Date()`로 실제 초를 읽어 처리

> 같은 날이라면 어느 컴퓨터에서, 몇 시에 열어도 **동일한 그래프**가 나타납니다.  
> 날짜가 바뀌면 새로운 패턴으로 시작됩니다.

## 산업 간 상관관계

| 산업 | 연동 산업 | 가중치 |
|------|----------|--------|
| 반도체 | AI, 로봇 | 40%, 20% |
| AI | 반도체, 로봇 | 40%, 25% |
| 2차전지 | 반도체 | 25% |
| 우주항공 | 2차전지 | 20% |
| 로봇 | AI, 반도체 | 35%, 20% |

반도체가 오르면 AI·로봇도 함께 오르는 구조로, 산업 간 투자 전략 판단 요소가 됩니다.

## 이벤트 시스템

### 뉴스 이벤트 (10초마다)
- 랜덤 산업에 호재 또는 악재 발생
- 가격 5~17% 즉시 변동
- 이후 3~5틱 동안 같은 방향 모멘텀 유지
- 산업별 호재 20개 + 악재 20개 (총 240개 뉴스 풀)

### 블랙스완 이벤트 (평균 25초마다)
- 랜덤 산업에 8~15% 급등 또는 급락
- `⚡ 블랙스완` 토스트 알림
- 이후 5틱 모멘텀 부여

---

## 거래 기능

- **매수** — 산업 버튼 클릭 후 `SPACE` 또는 버튼 재클릭
- **매도** — 보유 중인 산업 버튼 클릭 또는 `SPACE`
- **수익률 모달** — 매도 시 매수가 / 매도가 / 수익률(%) 팝업
- **다중 보유** — 여러 산업 동시 보유 가능

---

## 조작 방법

| 입력 | 동작 |
|------|------|
| 산업 버튼 클릭 | 선택 / 매도 |
| `SPACE` | 선택 산업 매수 · 보유 산업 매도 |
| `ESC` | 선택 취소 / 모달 닫기 |

---

## 실행 방법

1. `index_1.html` 을 브라우저로 열기 → 거래 화면 시작
2. (선택) `index_2.html` 을 두 번째 모니터에서 열기 → 차트 전용 화면

> 두 창은 **BroadcastChannel** 로 자동 동기화됩니다.  
> `index_2.html` 은 `index_1.html` 이 열려 있어야 데이터를 받습니다.
